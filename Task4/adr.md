### <a name="_qmphm5d6rvi3"></a>**Решение**
Диаграммы
- [контекста](context.drawio)
- [контейнеров](containers.drawio) 

При принятии решении о выборе технологий руководствовался следующим:
1. Часть технологий, использующихся в системе является не подходящими для дальнейшнего долгосрочного использования:
    - MS SQL и Oracle - большие санкионные риски
    - Delphi - сложности с наймом из-за низкой поулярности
    - ASP.NET MVC 4.5 на основе .NET Framework 4.5 - последний релиз версии 4.8.1 был в 2022 году
2. В компании используется только один подходящий стек технологии, в системе колл-центра - React, Sprint Boot, PostgreSQL. Поэтому для разработки новый сервисов и интерфейсов, там где это не доабвляет значительных дополнительных расходов, испольщуется только он. Данные стек достаточно поулярен и позволяет выполнить все функциональные и не функциональные требования.

### <a name="_bjrr7veeh80c"></a>**Альтернативы**
1. АБС предоставляет API для получения аткуальных ставок по депозитам, которое использует колл-центр
2. Публичный сайт предоставляет API для получения аткуальных ставок по депозитам, которое использует колл-центр
3. Интернет-банк предоставляет API для получения аткуальных ставок по депозитам, которое использует колл-центр

**Недостатки, ограничения, риски**

1. АБС, Колл-центр, Партнерский колл-центр имеют свои копии ставок на депозиты, с асинхронным процессом синхронизации. Данные в трех системах могут расходится в течение определенного времени.
